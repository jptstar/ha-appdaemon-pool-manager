# v0.10.11 — Température bassin certifiée uniquement PAC arrêtée

Cette version corrige une erreur de calibration visible dans `history-21.csv`.
La sonde placée dans le circuit hydraulique pouvait être certifiée pendant que
le compresseur chauffait encore. Elle mesurait alors l'eau localement réchauffée
par la PAC, jusqu'à environ 0,8–0,9 °C au-dessus de la température réellement
représentative du bassin.

## Comportement corrigé

- Une mesure ne peut plus être certifiée tant que la puissance PAC indique que
  le compresseur est actif.
- Pool Manager demande un arrêt protégé et respecte toujours la durée minimale
  de fonctionnement du compresseur.
- Lorsque la puissance PAC est réellement redescendue, le délai complet de
  brassage de l'eau puis le délai de stabilité de la sonde repartent de zéro.
- La valeur certifiée ne peut donc plus provenir de l'eau chaude restée dans le
  circuit de la PAC.

Cette correction stabilise la température estimée, l'apprentissage thermique
et les décisions du MPC. Elle ne change aucun nom d'entité Home Assistant, aucun
mode de chauffage et aucune protection PAC.

## Mise à jour

1. Mettre à jour Pool Manager vers v0.10.11 dans HACS.
2. Utiliser les YAML v0.10.11 fournis avec la configuration de l'installation.
3. Vérifier la configuration Home Assistant, puis redémarrer Home Assistant.
4. Redémarrer AppDaemon afin de charger le nouveau moteur.

Après le redémarrage, laisser le sélecteur **Dérogation exceptionnelle de
chauffe** sur **Suivre le plan Smart** sauf lorsqu'une décision ponctuelle est
souhaitée.
