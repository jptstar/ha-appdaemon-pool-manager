# v0.7.3 - Exact certified-measurement pump speed

This patch corrects the filtration-pump behavior during predictive temperature stabilization.

## Exact 70% reference cycle

The certified pool-temperature cycle now locks the pump to the configured measurement reference speed exactly:

```text
measurement active
-> pump = 70% exactly by default
-> 15-minute mixing window
-> stability check
-> certified pool temperature
```

Before this patch, the measurement speed acted only as a minimum. A quota, solar, catch-up or other normal strategy could therefore leave the pump at 80-100% during a certification cycle.

The reference cycle now overrides normal speed requests for its short duration and bypasses normal ramp/delay behavior so a pump already at 100% drops directly to 70%.

Outside a certified measurement cycle, the normal hydraulic rules remain unchanged, including the configured 47% low limit.

## Clearer dashboard wording

The predictive measurement state now uses:

```text
🌀 Stabilisation mesure température
```

No Home Assistant helper or AppDaemon YAML migration is required.
