# v0.10.15 — Correct PAC-stop waiting diagnostics

This patch fixes the certified-temperature sequence when a Smart/MPC heating cycle is already running and Pool Manager must wait for the PAC minimum-on anti-cycle before stopping the compressor.

## What changes

- A new internal measurement phase, `waiting_pac_stop`, is reported while PAC electrical power still confirms an active compressor.
- Home Assistant now shows **attente arrêt PAC** instead of suggesting a missing hydraulic flow while the pump is already circulating correctly.
- The countdown uses the remaining PAC minimum-on delay when available.
- The original measurement request time is preserved during the wait; it is no longer rewritten on every control tick.
- The 15-minute circulation delay and probe-stability delay still start from zero only after the compressor has physically stopped, preserving the protection introduced in v0.10.11.

## Compatibility

No Home Assistant entity IDs or configuration keys change. Existing Smart, end-of-season, Turbo and filtration behavior remains compatible.

## Validation

196 automated tests cover the pool manager after this change, including regressions for the PAC-stop wait phase and timestamp preservation.
