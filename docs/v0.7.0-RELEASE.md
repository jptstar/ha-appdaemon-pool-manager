# v0.7.0 - Self-learning thermal recovery

Pool Manager v0.7.0 replaces the fixed predictive-heating timetable with a simpler self-learning thermal planner.

- Keeps the weather outlook up to 15 days and identifies credible bathing days from temperature, sun/clouds, rain and wind.
- Removes the synthetic 16:00 bathing deadline and the fixed previous-day / morning / emergency heating slots.
- Learns the real pool-water gain in °C/h separately by PAC preset and outdoor-temperature range.
- Learns passive overnight cooling from the water/air temperature difference and pool-cover state.
- Persists the learned thermal models outside the HACS-managed package so restarts and HACS upgrades do not erase them.
- Calculates the latest recovery start day from the learned thermal behavior instead of using a fixed J-2/J-5 rule.
- Skips a weather-friendly day if the pool cannot actually recover to target in time.
- Prefers Smart daytime heating, then Turbo daytime, and only authorizes night heating when daytime capacity is insufficient.
- Applies the same long-bad-weather stop/restart strategy to Automatique and Fin de saison • Smart.
- Adds an optional absolute minimum-water-temperature floor so the pool can remain thermally recoverable without maintaining the full setpoint.
- Keeps `brassage_nuit_intelligent: false` independent from genuine heating demand: periodic night mixing stays disabled while an exceptional pump+PAC recovery may still run at night.
- Removes the obsolete duplicate end-of-season planner and the old predictive slot anti-chatter layer.
- Publishes clearer diagnostics: next bathing day, recovery start date, recommended PAC preset, night-heating requirement, predicted night loss, projected no-heat temperature, and learned thermal models.

Existing safety priorities are unchanged: Arrêt Forcé, Hors Gel, pump-first PAC startup, minimum-flow protection, PAC fail-safe and post-circulation remain above predictive decisions.

The new `chauffage_predictif_temperature_min_eau_c` is optional. If omitted, Pool Manager keeps the compatible profile floors (target -2 °C in Automatique and target -4 °C in Fin de saison by default).
