# v0.6.3 - Runtime stability fixes

Pool Manager v0.6.3 fixes three production issues affecting Intelligent filtration, predictive heating and Aquagem/iSaver speed control.

- Honors `brassage_nuit_intelligent: false` so Intelligent mode no longer starts periodic night circulation when night mixing is disabled.
- Prevents predictive heating from creating an immediate emergency slot before the configured morning heating window; for example, a target-day plan with `chauffage_predictif_matin_debut: "07:00:00"` now waits until 07:00 instead of starting around 05:xx.
- Stabilizes an already-started predictive heating slot so 30-second safety/policy reevaluations cannot alternate PAC Heat/Off around a moving schedule boundary.
- Keeps Pool Manager authoritative over Aquagem/iSaver speed in Intelligent and Hors Gel modes when local-panel assist is disabled by periodically reasserting the last requested speed before the pump watchdog can restore a local setpoint.
- Preserves local-panel handoff behavior in `Température` and `Marche Forcée` modes.
- Adds regression tests for night-mixing disablement, predictive pre-window emergency suppression, predictive anti-chatter and iSaver remote-speed keepalive.

No Home Assistant helper or YAML migration is required. Existing installations automatically use the defaults (`pompe_remote_keepalive_s: 30`, `chauffage_predictif_tempo_min_on_s: 900`) unless explicitly overridden.

Safety priorities remain unchanged: Arrêt Forcé, Hors Gel protection, pump-first PAC flow confirmation, PAC flow fail-safe and post-circulation remain above predictive and energy-optimization decisions.
