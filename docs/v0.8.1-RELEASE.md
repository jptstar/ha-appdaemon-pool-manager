# v0.8.1 — Aquagem remote-authority stability

This patch fixes a production oscillation where an Aquagem iSaver could repeatedly jump back to its locally remembered speed after Pool Manager had already selected a lower automatic speed.

A typical observed cycle was:

```text
Pool Manager -> 70% / custom speed
~70 s later  -> physical panel regains authority
pump         -> Max / 2900 rpm
Pool Manager -> ramps it back down
~70 s later  -> 2900 rpm again
```

The timing matches Aquagem Pump's intentional `Retour au contrôle local` handover window. The feature is useful for manual operation, but it must not release authority while Pool Manager owns the pump automatically.

## Correct mode ownership

v0.8.1 makes ownership explicit:

```text
Intelligent   -> Pool Manager owns speed
Hors Gel      -> Pool Manager owns speed
Température   -> local-panel handover allowed
Marche Forcée -> local-panel handover allowed
Arrêt Forcé   -> safety authority
```

## Remote keepalive

In Pool-Manager-owned modes, the controller now reasserts the last desired pump speed before the iSaver watchdog can expire. The default is:

```yaml
pompe_remote_keepalive_s: 30
```

Known Aquagem/iSaver fan entity ids enable this protection automatically even if the optional local-control switch was not configured.

Generic fan integrations can opt in explicitly:

```yaml
pompe_remote_keepalive: true
```

## Recommended Aquagem wiring

For the cleanest integration, expose the Aquagem local-control entities to Pool Manager:

```yaml
entity_pompe_local_panel_assist: switch.pool_pump_return_to_local_control
entity_pompe_local_control_available: binary_sensor.pool_pump_local_control_available
entity_pompe_local_control_remaining: sensor.pool_pump_time_until_local_control
```

When the switch is available, Pool Manager sets `Retour au contrôle local` OFF in Intelligent/Hors Gel and restores the correct policy immediately if that switch is toggled back on.

## No MPC change

The v0.8 Adaptive Thermal Model + MPC is unchanged by this patch. This fix only stabilizes pump ownership and prevents the external/local handover from undoing the speed chosen by Pool Manager.

No Home Assistant helper migration is required.
