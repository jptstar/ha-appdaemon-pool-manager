# v0.6.2 - AppDaemon weather forecast hotfix

Pool Manager v0.6.2 fixes predictive weather retrieval with AppDaemon 4.5+.

- Fixes the Home Assistant `weather.get_forecasts` service response request by translating the legacy internal `return_result=True` flag to AppDaemon's supported `return_response=True` argument.
- Prevents the obsolete `return_result` flag from being sent as service data to Home Assistant.
- Restores predictive-heating access to the daily forecast response, including up to 15 days when supplied by the configured weather provider.
- Keeps the existing response decoder and all v0.6.1 strategic weighting / operational-horizon behavior unchanged.
- Requires no YAML or Home Assistant helper migration.

Safety priorities remain unchanged: forced stop, Hors Gel, pump-first PAC flow confirmation, PAC flow fail-safe and post-circulation stay above predictive decisions.
