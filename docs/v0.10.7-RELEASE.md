# v0.10.7 — Préchauffage de jour et autorisation nocturne

Cette version corrige une régression introduite par la confirmation de chauffe
exceptionnelle en v0.10.5. Refuser la chauffe nocturne recalculait auparavant
le plan complet en mode économique. Ce recalcul pouvait supprimer un
préchauffage diurne déjà utile, retirer la demande PAC puis laisser
l'arbitrage solaire arrêter normalement la pompe.

La décision nocturne ne remplace désormais plus le plan MPC complet :

- **Journée seulement** conserve le préchauffage Smart prévu avant la fin de la
  plage diurne et bloque uniquement la chauffe nocturne exceptionnelle ;
- **Autoriser cette nuit** conserve le plan complet, y compris après minuit ;
- **Turbo 1 h maintenant** reste une accélération immédiate distincte ;
- **Suspendre aujourd'hui** arrête explicitement le chauffage prédictif jusqu'à
  minuit.

Sans réponse, Pool Manager applique **Journée seulement**. La PAC conserve
alors sa priorité hydraulique pendant le préchauffage : la pompe reste au moins
à `vitesse_min_pac_active` (47 % dans la configuration d'exemple), même sans
surplus photovoltaïque. Le solaire continue à optimiser la vitesse et le coût,
mais il ne peut pas annuler une demande PAC active. Les protections de débit,
l'arrêt forcé et les sécurités restent prioritaires.

## Home Assistant

Le capteur existant `sensor.piscine_decision_chauffage` expose une nouvelle
action temporaire `night`. Ajouter le script suivant au package :

```yaml
script:
  piscine_decision_nuit:
    alias: Piscine - autoriser la chauffe nocturne
    sequence:
      - event: mobile_app_notification_action
        event_data:
          action: "{{ state_attr('sensor.piscine_decision_chauffage', 'night') or '' }}"
```

Les scripts et entités historiques ne sont ni renommés ni supprimés. Le script
`piscine_decision_economie` signifie désormais explicitement « journée
seulement ». Une carte compacte complète est disponible dans
`examples/pool_decision_card.yaml`.

Après mise à jour HACS, recharger l'application Pool Manager dans AppDaemon et
ajouter le nouveau script Home Assistant avant d'utiliser le bouton nocturne.
