# v0.8.0 — Adaptive Thermal Model + MPC

Pool Manager v0.8 replaces the default predictive recovery planner with an **Adaptive Thermal Model + receding-horizon Model Predictive Control (MPC)** engine.

## What changes

The controller no longer asks only whether today's water is above a rule-based recovery trajectory. It now simulates future thermal strategies up to the selected bathing window:

```text
OFF
Smart for 1 h, 2 h, ...
Turbo for 1 h, 2 h, ...
```

For each credible bathing opportunity it predicts water temperature and PAC energy, then selects the lowest-energy reachable path.

The optimization runs again whenever the control loop receives new information. The multi-day MPC plan is therefore a forecast, not a rigid timer.

## Adaptive thermal model

v0.8 directly reuses the certified learning introduced in v0.7:

- PAC net heating rate by preset and outdoor-temperature range;
- learned PAC electrical power and kWh/°C;
- passive pool loss by water/air delta and cover state;
- certified water temperatures only.

While the installation is still learning, real samples are blended with conservative configured fallbacks. The status sensor publishes a `model_confidence` summary so cold-start behavior is visible.

The learned file remains `pool_manager_thermal_learning.json`; existing learning is retained across the upgrade.

## Dynamic reserve instead of a fixed operating floor

`chauffage_predictif_temperature_min_eau_c` remains the **absolute floor**.

MPC also publishes `adaptive_floor_temperature`: the minimum current water temperature from which the selected optimized plan can still reach the bathing target while respecting the absolute floor.

Example:

```text
Absolute floor       22.0 °C
Adaptive floor       25.4 °C
Water now            26.1 °C
Decision             WAIT
```

If future recovery capacity becomes tight, the adaptive floor rises automatically. If several efficient heating opportunities remain, it can fall back toward the absolute floor.

## Energy-aware timing

MPC uses learned PAC power when available and cold-start power assumptions otherwise. It can therefore prefer a later warmer day when the PAC is predicted to recover the same heat with less energy.

Turbo has an optimization penalty so Smart is preferred when both strategies remain practical.

Night heating is evaluated only after no daytime-only solution can reach the same selected bathing window. It also carries a larger penalty, keeping night recovery exceptional.

## Dashboard

The predictive status sensor adds:

- `planner: MPC`
- `model_confidence`
- `adaptive_floor_temperature`
- `mpc_energy_kwh`
- `mpc_night_energy_required`
- `mpc_plan`

Each `forecast` row can also expose:

- `mpc_heat_hours`
- `mpc_night_heat_hours`
- `mpc_preset`
- `mpc_energy_kwh`
- `predicted_water_start`
- `predicted_water_end`

This keeps the 15-day weather view while showing which days the optimizer currently expects to heat.

## Safety boundary

MPC does **not** own safety.

Forced stop, freeze protection, PAC minimum flow, pump/PAC sequencing, chlorination protection and other fail-safes remain deterministic and keep higher priority than the optimizer.

Certified water measurement remains the same v0.7.3 reference cycle: the pump is locked exactly to the configured measurement speed (70% by default), then the stability check certifies the water temperature.

## Configuration

MPC is enabled by default when predictive heating is enabled:

```yaml
chauffage_predictif: true
chauffage_predictif_mpc: true
```

Optional tuning:

```yaml
chauffage_predictif_mpc_pas_h: 1.0
chauffage_predictif_mpc_pas_temperature_c: 0.2
chauffage_predictif_mpc_puissance_smart_w: 1200
chauffage_predictif_mpc_puissance_turbo_w: 1900
chauffage_predictif_mpc_penalite_turbo_kwh_h: 0.08
chauffage_predictif_mpc_penalite_nuit_kwh_h: 0.35
```

Normally these defaults should be left unchanged while the thermal model gathers real samples.

To compare or temporarily roll back to the v0.7 trajectory planner:

```yaml
chauffage_predictif_mpc: false
```

No new Home Assistant helper is required.
